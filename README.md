# Кафедра ИС — табло текущего расписания

Живое веб-табло: какие занятия кафедры «Информационные системы» идут сейчас,
в каких аудиториях, у кого и по какому предмету. Данные — на 1 академический
период 2026-2027 уч. года.

**Готовый файл:** [`dist/kafedra-is-board.html`](dist/kafedra-is-board.html) —
самодостаточный HTML (данные внутри), можно открыть в браузере или
разместить на любом хостинге/экране.

## Возможности

- Реальное время в часовом поясе Алматы/Астана (UTC+5, фиксировано).
- Режимы просмотра: 1ч (список актуальных занятий), 3ч (Gantt-сетка по аудиториям), весь день (сетка), неделя (список по дням).
- Движущаяся линия «сейчас» на сетке.
- Фильтры: преподаватель, аудитория, группа (подстрока).
- Клик по занятию — попап с полной карточкой (предмет, ФИО, группа, уровень, аудитория, время).
- Цветовая кодировка по типу занятия (лекция / практика / лабораторная), пунктир — онлайн/дистант.

## Структура репозитория

```
src/              исходники табло
  board.html      разметка + стили + плейсхолдер для скриптов
  script.js       вся логика (рендер, фильтры, попап, часовые пояса)
  lessons_data.js сгенерированные данные занятий (const LESSONS = [...])
data/
  results.json         сырые совпадения "преподаватель → занятие" после сопоставления ФИО
  parsed_lessons.json  разобранные записи (день/время/аудитория/тип/дисциплина) — источник lessons_data.js
scripts/
  teachers.py       список 47 преподавателей кафедры ИС
  extract.py        разбор исходных xlsx-расписаний, сопоставление ФИО (с учётом опечаток/казахских букв)
  parse_lessons.py  превращает results.json в parsed_lessons.json (аудитория, тип, дисциплина, время)
  build_report.py   собирает Excel-отчёт (Кафедра_ИС_занятия_преподавателей_2026-2027.xlsx)
  build.py          собирает dist/kafedra-is-board.html из src/*
dist/
  kafedra-is-board.html                          готовое табло (открыть в браузере)
  Кафедра_ИС_занятия_преподавателей_2026-2027.xlsx  табличный отчёт по всем преподавателям
index.html          зеркало dist/kafedra-is-board.html в корне — для GitHub Pages
                     (Settings → Pages → Deploy from branch → main / root)
```

## Пересборка после изменения данных

Исходные файлы расписаний (xlsx от деканата) в репозиторий не включены —
`extract.py` и `parse_lessons.py` ожидают их в `/mnt/user-data/uploads/`
(путь под окружение Claude, при переносе скрипта на обычный сервер
поменяйте `UPLOAD_DIR`/пути внутри файлов).

```bash
python3 scripts/extract.py          # -> data/results.json
python3 scripts/parse_lessons.py    # -> data/parsed_lessons.json (+ src/lessons_data.js обновите вручную/скриптом)
python3 scripts/build.py            # -> dist/kafedra-is-board.html и корневой index.html
python3 scripts/build_report.py     # -> dist/Кафедра_ИС_занятия_преподавателей_2026-2027.xlsx
```

## Известные ограничения

- В табло попадают только занятия 47 преподавателей кафедры ИС — параллельные
  занятия других кафедр в тех же аудиториях не отображаются.
- Часть преподавателей не встретилась в загруженных файлах расписаний
  (см. лист «Сводка» в Excel-отчёте) — вероятно, в этот период без нагрузки
  или их файл не входил в исходный набор.
